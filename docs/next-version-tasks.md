# 下一版开发任务与验收对应

更新日期：2026-11-17。状态：全部待开展；本次只新增规划文档，没有实现下列功能。

执行前置：项目发起人先完成辅导员需求调研和 PRD，再据此修订本清单；调研完成前不启动功能实现。

需求与验收的唯一依据为 [下一版 PRD](next-version-prd.md)。任务中的文件位置是建议修改范围，新增文件名在实现时按实际职责确定。工期须在样表、模型和设备条件明确后估算，不把下表当作排期承诺。

## 1. 开发原则

- 每个任务只解决其对应的当前需求，不预建多学校、多模型、跨端同步或权限平台。
- 继续使用 PySide6、现有后台线程与 Selenium 填报流程；不为界面美化改写浏览器引擎。
- 输入文件、用户审核、模型响应、网络和本地写入是需要明确处理的边界；错误必须可见，不静默回退或默认成功。
- 新持久化是增量增加，不改写已有个人进度；源问卷保持不变。
- 单个任务完成时执行对应验证，后续有相关改动才重跑对应测试；发布前完成必要回归。
- 不批量删除文件或目录；如后续工作需要批量清理，由用户手动处理。

## 3. 建议实施顺序

### 里程碑 M1：规则和手工审核流程可用

完成 T01、T02、T04，以及 T07 中人工草稿的审核队列衔接。先用旧表和虚构素材验证“编辑—审核—模拟填报”。T05 的选型工作可以在这一阶段开展，不以模型尚未确定阻塞独立工作。

退出条件：时间/正文限制、逐条审核、修改撤销审核、仅登录模式和批次数量已验证。问卷样表未到时，不能宣布问卷导入完成。

### 里程碑 M2：问卷到草稿闭环可用

完成 T03、T05、T06 和 T09 的对应部分。对所选问卷模板完成素材导入和对照，实际关键词能生成待审核草稿；只有问卷时生成摘要与提纲。

退出条件：固定评测未出现 PRD 定义的关键事实错误；单条生成失败可见且不覆盖手工编辑；使用当前学生素材的边界已经验证。

### 里程碑 M3：可恢复、可打包、可试用

完成 T07 余项、T08—T11，并汇总 T10 的验证结果。检查问卷、旧表两条入口及 Windows 环境。

退出条件：AC01—AC18 有通过证据，所有真实数据与发布阻塞项有结论，学校保存的成功/失败/不确定结果处理均通过验证。随后进入 T12；未通过时不扩大真实试用。
